1. PROJEKTFELADAT ÉS CÉLKITŰZÉSEK
═══════════════════════════════════════════════════════════════════════════════

1.1. FELADAT LEÍRÁSA
─────────────────────

A projekt célja egy komplett webalkalmazás fejlesztése egy borbély szalon
(Beach Barbershop) számára, amely támogatja az online foglalásokat, az 
e-commerce funkcionalitást és az adminisztratív feladatokat.

Az alkalmazásnak meg kell felelnie a következő követelményeknek:
  • Felhasználó autentikáció és regisztráció rendszere
  • Időpontfoglalási modul
  • E-commerce webshop integráció
  • Felhasználói profil kezelés
  • Rendszeradminisztrátori felület
  • Legalább 3 felhasználói szerepkör (USER, BARBER, ADMIN)
  • Responsive, modern felhasználói felület


1.2. FUNKTIKAI KÖVETELMÉNYEK
──────────────────────────────

VÉGFELHASZNÁLÓ FUNKCIÓK:
  ✓ Regisztráció és bejelentkezés
  ✓ Időpont foglalása szolgáltatások közül választva
  ✓ Foglalások kezelése (megtekintés, törlés)
  ✓ Termékek vásárlása a webshopból
  ✓ Rendelések kezelése és nyomonkövetése
  ✓ Saját profil szerkesztése

ADMINISZTRATÍV FUNKCIÓK:
  ✓ Összes foglalás megtekintése és kezelése
  ✓ Összes rendelés megtekintése és kezelése
  ✓ Felhasználók adminisztrálása (szerkesztés, jelszó módosítás, törlés)
  ✓ Felhasználói adatok szűrése és keresése

2. TERVEZÉS ÉS SPECIFIKÁCIÓ
═══════════════════════════════════════════════════════════════════════════════

2.1. ARCHITEKTÚRA
──────────────────

Az alkalmazás MVC (Model-View-Controller) architekturális mintát követve készült:

  FRONTEND (View):
    • HTML5/EJS template engine
    • CSS3 + modern styling
    • Vanilla JavaScript + DOM manipuláció
    
  BACKEND (Controller & Model):
    • Node.js + Express.js szerver
    • Prisma ORM az adatbázis kezeléshez
    • RESTful API végpontok


2.2. TECHNOLÓGIAI STACK
────────────────────────

BACKEND TECHNOLÓGIÁK:
  • Node.js v16+           – JavaScript futtatási környezet
  • Express.js             – Web framework
  • Prisma ORM            – Adatbázis kezelő
  • SQLite                – Relációs adatbázis
  • Bcrypt                – Jelszó titkosítás

FRONTEND TECHNOLÓGIÁK:
  • HTML5                 – Szemantikus weboldal szerkezet
  • CSS3                  – Modern styling, flexbox, grid
  • EJS                   – Szerver oldali template motor
  • Vanilla JavaScript    – Kliens oldali dinamika

FEJLESZTŐI ESZKÖZÖK:
  • npm                   – Csomagkezelő
  • Prisma CLI           – ORM eszközök

3.1. ADATMODELL
────────────────

Az alkalmazás háromfő entitást használ, melyek relációban állnak egymással:


  ┌─────────────────────────────────────────────────────────────────┐
  │ USER (Felhasználó)                                              │
  ├─────────────────────────────────────────────────────────────────┤
  │ • id (Int)              - Elsődleges kulcs (auto-increment)     │
  │ • felhnev (String)      - Felhasználónév                        │
  │ • email (String)        - Elektronikus levelezési cím           │
  │ • password (String)     - Bcrypt-tel titkosított jelszó         │
  │ • telefonszam (String)  - Elsődleges telefonszám               │
  │ • pnumber (String)      - Másodlagos telefonszám               │
  │ • role (String)         - Felhasználói szerep (USER/BARBER/ADMIN)
  │ • createdAt (DateTime)  - Fiók létrehozásának időpontja        │
  │                                                                  │
  │ RELÁCIÓK:                                                        │
  │ ↓ 1-N → Booking (egy felhasználónak több foglalása lehet)       │
  │ ↓ 1-N → Order (egy felhasználónak több rendelése lehet)         │
  └─────────────────────────────────────────────────────────────────┘


  ┌─────────────────────────────────────────────────────────────────┐
  │ BOOKING (Foglalás)                                              │
  ├─────────────────────────────────────────────────────────────────┤
  │ • id (Int)              - Elsődleges kulcs (auto-increment)     │
  │ • userId (Int)          - Idegenkulcs (User.id)                 │
  │ • datetime (DateTime)   - Foglalás időpontja                    │
  │ • service (String)      - Szolgáltatás típusa                   │
  │                                                                  │
  │ RELÁCIÓK:                                                        │
  │ ↑ N-1 ← User (minden foglalás egy felhasználóhoz tartozik)       │
  └─────────────────────────────────────────────────────────────────┘


  ┌─────────────────────────────────────────────────────────────────┐
  │ ORDER (Rendelés)                                                │
  ├─────────────────────────────────────────────────────────────────┤
  │ • id (Int)              - Elsődleges kulcs (auto-increment)     │
  │ • userId (Int)          - Idegenkulcs (User.id)                 │
  │ • products (String)     - JSON formátumú termékadatok           │
  │ • totalPrice (Int)      - Teljes rendelési ár (forintban)       │
  │ • shippingType (String) - Szállítási mód (home / pickup)        │
  │ • createdAt (DateTime)  - Rendelés létrehozásának időpontja     │
  │                                                                  │
  │ RELÁCIÓK:                                                        │
  │ ↑ N-1 ← User (minden rendelés egy felhasználóhoz tartozik)       │
  └─────────────────────────────────────────────────────────────────┘


3.2. NORMALIZÁLÁS ÉS KONZISZTENCIA
──────────────────────────────────────

  ✓ Az adatmodell 3. normálformában (3NF) van megvalósítva
  ✓ Összes idegen kulcs konfigurálva van relációs integritás fenntartásához
  ✓ Jelszavak bcrypt algoritmussal vannak titkosítva
  ✓ Dátumok ISO 8601 formátumban vannak tárolva

6.1. BACKEND IMPLEMENTÁCIÓ
────────────────────────────

SZERVER INDÍTÁSA (index.js):
  • Express alkalmazás inicializálása
  • Middleware-ek regisztrálása (body-parser, cors, session)
  • Static fájlok kiszolgálása
  • EJS view engine konfigurálása
  • Session kezelés (express-session)
  • Error handling middleware

API VÉGPONTOK:

  AUTENTIKÁCIÓ:
    POST /api/register       → Regisztráció feldolgozása
    POST /api/login          → Bejelentkezés feldolgozása
    GET /api/logout          → Kijelentkezés

  FELHASZNÁLÓ FOGLALÁSOK:
    GET /api/bookings        → Bejelentkezett felhasználó foglalásai
    POST /api/booking        → Új foglalás létrehozása
    DELETE /api/booking/:id  → Foglalás törlése

  FELHASZNÁLÓ RENDELÉSEK:
    GET /api/orders          → Bejelentkezett felhasználó rendeléseiden
    POST /api/order          → Új rendelés létrehozása

  ADMIN VÉGPONTOK:
    GET /api/admin/bookings              → Összes foglalás
    GET /api/admin/orders                → Összes rendelés
    DELETE /api/admin/order/:id          → Rendelés törlése
    GET /api/admin/users                 → Összes felhasználó
    POST /api/admin/user/:id/update      → Felhasználó módosítása
    POST /api/admin/user/:id/password    → Jelszó módosítása
    DELETE /api/admin/user/:id           → Felhasználó törlése


JELSZÓ TITKOSÍTÁS:
  • Bcrypt algoritmus alkalmazása
  • 10 salt round
  • Jelszó ellenőrzés bejelentkezéskor

SESSION KEZELÉS:
  • Express-session middleware
  • Szerver oldali session tár
  • Secure cookie flag
  • 24 órás session érvényesség

6.3. ADATBÁZIS MŰVELETEK

7.2. TELEPÍTÉSI LÉPÉSEK
─────────────────────────

1. PROJEKT KLÓNOZÁSA VAGY KICSOMAGOLÁSA:
   Az összes fájlt helyezzük a Projekt/ mappába

2. FÜGGŐSÉGEK TELEPÍTÉSE:
   $ npm install

3. PRISMA ADATBÁZIS INICIALIZÁLÁSA:
   $ npx prisma migrate dev
   Ez létrehozza az SQLite adatbázist és az összes táblát

4. ADMIN FELHASZNÁLÓ LÉTREHOZÁSA (INTERAKTÍV):
   $ node scripts/createAdminInteractive.mjs
   Követd az utasításokat (felhasználónév, email, jelszó)

5. SZERVER INDÍTÁSA:
   $ npm start
   vagy
   $ node src/index.js

6. ALKALMAZÁS MEGNYITÁSA:
   A böngészőben nyisd meg: http://localhost:3000


7.3. KONFIGURÁCIÓS VÁLTOZÓK
──────────────────────────────

Ha szükséges, a szerverazonosítókat az index.js fájlban módosíthatod:
  • PORT = 3000 (szerver port)
  • SESSION_SECRET = "your-secret-key"
  • DATABASE_URL = "file:./dev.db"
