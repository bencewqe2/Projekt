1. PROJEKT ÁTTEKINTÉSE
===============================================================================

Beach Barbershop egy modern weboldal egy fodrászati szalonnak, amely lehetővé 
teszi az ügyfeleknek hogy:
- Foglalásokat tudjanak téni
- Webshop-ból termékeket tudjanak vásárolni
- Saját fiókot kezeljenek
- Rendeléseiket nyomon követhessék

Az adminisztrátorok képesek:
- Foglalásokat kezelni
- Rendeléseket kezelni
- Felhasználókat kezelni

===============================================================================
2. TECHNOLÓGIÁK
===============================================================================

Backend:

4. ADATBÁZIS SÉMA
===============================================================================

User (Felhasználó)
- id: Int (Primary Key)
- felhnev: String (Felhasználónév)
- email: String (Email cím)
- password: String (Titkosított jelszó)
- telefonszam: String (Telefonszám)
- pnumber: String (Másik telefonszám)
- role: String (USER, BARBER, ADMIN)
- createdAt: DateTime (Létrehozás dátuma)

Booking (Foglalás)
- id: Int (Primary Key)
- userId: Int (Foreign Key)
- datetime: DateTime (Foglalás időpontja)
- service: String (Szolgáltatás típusa)
- user: User (Relációs hivatkozás)

Order (Rendelés)
- id: Int (Primary Key)
- userId: Int (Foreign Key)
- products: String (JSON formátumban)
- totalPrice: Int (Teljes ár)
- shippingType: String (home / pickup)
- createdAt: DateTime (Létrehozás dátuma)
- user: User (Relációs hivatkozás)

5. API VÉGPONTOK
===============================================================================

AUTENTIKÁCIÓ:
POST /api/register          - Felhasználó regisztrálása
POST /api/login             - Bejelentkezés
GET /api/logout             - Kijelentkezés

FOGLALÁSOK (Felhasználó):
GET /api/bookings           - Felhasználó foglalásai
POST /api/booking           - Új foglalás létrehozása
DELETE /api/booking/:id     - Foglalás törlése

RENDELÉSEK (Felhasználó):
GET /api/orders             - Felhasználó rendelései
POST /api/order             - Új rendelés létrehozása

ADMIN API:
GET /api/admin/bookings     - Összes foglalás
GET /api/admin/orders       - Összes rendelés
DELETE /api/admin/order/:id - Rendelés törlése (admin)
GET /api/admin/users        - Összes felhasználó
POST /api/admin/user/:id/update    - Felhasználó szerkesztése
POST /api/admin/user/:id/password  - Jelszó módosítása
DELETE /api/admin/user/:id         - Felhasználó törlése

7. TELEPÍTÉSI UTASÍTÁSOK
===============================================================================

1. Függőségek telepítése:
   npm install

2. Adatbázis inicializálása:
   npx prisma migrate dev

3. Admin felhasználó létrehozása (interaktív):
   node scripts/createAdminInteractive.mjs

4. Szerver indítása:
   npm start
   vagy
   node src/index.js

5. Böngészőben megnyitni:
   http://localhost:3000

8. FELHASZNÁLÁSI ÚTMUTATÓ
===============================================================================

8.1 REGISZTRÁCIÓ
- Kattints a "Regisztráció" linkre
- Töltsd ki a szükséges adatokat
- Kattints a "Regisztráció" gombra
- Sikeres regisztráció után átirányítódni fog a bejelentkezésre

8.2 BEJELENTKEZÉS
- Kattints a "Bejelentkezés" linkre
- Add meg az email-ed és jelszavad
- Kattints a "Bejelentkezés" gombra

8.3 FOGLALÁS LÉTREHOZÁSA
- Menj a "Foglalás" oldalra
- Válassz időpontot és szolgáltatást
- Kattints a "Foglalás" gombra
- A foglalás megjelenik a fiók oldalon

8.4 WEBSHOP VÁSÁRLÁS
- Menj a "Shop" oldalra
- Szűrd a termékeket kategóriák szerint
- Válassz terméket és mennyiséget
- Add hozzá a kosárhoz
- Menj a kosárhoz és kattints a "Fizetés" gombra

8.5 FIÓK KEZELÉS
- Kattints a profil ikonra
- Válaszd a "Fiók" opciót
- Megtekintheted:
  * Fiók részleteidet
  * Foglalásaidat
  * Rendeléseidet

9.1 ADMIN BEJELENTKEZÉS

  * Új jelszót adhatsz meg
